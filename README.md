# 🚨 CrisisLens — Disaster Tweet Classification using NLP

CrisisLens is an NLP + Machine Learning project that classifies tweets as either describing a **real disaster** or **not a disaster**, using text-based features extracted with TF-IDF and a suite of classical ML models.

## 📊 Dataset

- **File:** `tweets.csv`
- **Dataset Source:** [Kaggle](www.kaggle.com/datasets/vstepanenko/disaster-tweets)
- **Rows:** 11,370 tweets
- **Columns:**
  - `id` — unique tweet identifier
  - `keyword` — keyword extracted from the tweet (may be blank)
  - `location` — user-reported location (often missing)
  - `text` — the raw tweet text
  - `target` — label (`1` = real disaster, `0` = not a disaster)
- **Class balance:** ~81% not-disaster, ~19% disaster (imbalanced)

## 🧠 Approach

1. **EDA** — class distribution, top disaster keywords, tweet length distribution, word clouds.
2. **Text cleaning** — lowercasing, URL/mention/hashtag removal, punctuation & digit removal, stopword removal, lemmatization (NLTK).
3. **Feature extraction** — TF-IDF vectorization (unigrams + bigrams, 8,000 features).
4. **Modeling** — four models trained and compared:
   - Logistic Regression (`class_weight='balanced'`)
   - Multinomial Naive Bayes
   - Linear SVM (calibrated for probabilities)
   - XGBoost (`scale_pos_weight` for imbalance)
5. **Evaluation** — Accuracy, Precision, Recall, F1-score, ROC-AUC, Confusion Matrix.
6. **Deployment** — best model (Logistic Regression) and TF-IDF vectorizer are saved with `joblib` and served through a Streamlit web app.

## 🏆 Results

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|---|
| **Logistic Regression** ✅ | 0.852 | 0.579 | 0.747 | **0.652** | **0.906** |
| Multinomial Naive Bayes | 0.869 | 0.883 | 0.340 | 0.491 | 0.887 |
| Linear SVM | 0.880 | 0.748 | 0.532 | 0.622 | 0.901 |
| XGBoost | 0.850 | 0.590 | 0.641 | 0.615 | 0.873 |

**Logistic Regression** was selected as the final model — it has the best F1-score and ROC-AUC, and its higher recall means fewer real disasters are missed, which matters most for a safety-critical use case like this.

## ⚙️ Setup & Installation

```bash
# 1. Clone / download the project folder, then move into it
cd CrisisLens

# 2. (Recommended) create a virtual environment
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt
```

## ▶️ Running the Notebook

Open `CrisisLens_Disaster_Tweet_Classification.ipynb` in Jupyter Notebook/Lab or VS Code and run all cells top to bottom. This regenerates `model/model.pkl` and `model/vectorizer.pkl`.

```bash
jupyter notebook CrisisLens_Disaster_Tweet_Classification.ipynb
```

## ▶️ Running the Streamlit App

Make sure `model/model.pkl` and `model/vectorizer.pkl` exist (either run the notebook once, or use the ones already included), then:

```bash
streamlit run app.py
```

The app opens in your browser at `http://localhost:8501` and offers:
- **Single Tweet tab** — type or pick an example tweet and get an instant Disaster / Not Disaster prediction with a confidence score.
- **Batch (CSV) Prediction tab** — upload a CSV with a `text`/`tweet` column and download predictions for the whole file.
- **Insights tab** — browse every graph generated in the notebook (class distribution, top keywords, word clouds, model comparison, ROC curve, confusion matrix) and the full metrics table for all 4 models.
